# Machine Learning Short Codes

This repository contains short, practical Python code examples for important machine-learning topics.

Each notebook focuses on one concept and includes:

- A short explanation
- A small example dataset
- Python implementation
- Visualization where useful
- Model evaluation
- Key takeaways

## Topics Cover

- Python, NumPy, and Pandas basics
- Data visualization
- Data preprocessing
- Feature engineering
- Linear regression
- Logistic regression
- Decision trees
- Random forests
- Support vector machines
- K-nearest neighbors
- Naive Bayes
- K-Means clustering
- Principal Component Analysis
- Model evaluation
- Hyperparameter tuning
- Neural networks
- Basic model deployment

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
